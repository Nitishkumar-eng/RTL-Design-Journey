# RTL Design Journey

> A personal engineering journey to learn Register Transfer Level (RTL) Design from first principles through structured theory, hands-on implementation, verification, and FPGA deployment.

---

## About

This repository documents my progress as I learn digital hardware design, starting from the fundamentals and gradually working towards designing a complete RISC-V based System-on-Chip (SoC).

Rather than collecting isolated Verilog examples, the goal is to build reusable hardware modules, understand the engineering decisions behind them, and follow an industry-inspired RTL development workflow.

---

## Objectives

- Learn Digital Design from fundamentals
- Master Verilog HDL for synthesizable RTL
- Develop strong RTL coding practices
- Learn verification using testbenches and waveform analysis
- Build reusable and modular hardware components
- Understand processor architecture through RISC-V
- Learn synthesis and timing concepts
- Deploy designs on FPGA hardware
- Maintain professional documentation throughout the journey

---

## Engineering Workflow

Every module in this repository follows the same development process.

```
Requirement Analysis
        ↓
Concept & Theory
        ↓
Architecture Design
        ↓
RTL Implementation
        ↓
Verification
        ↓
Simulation
        ↓
Waveform Analysis
        ↓
Documentation
        ↓
FPGA Implementation
```

## Repository Philosophy

This repository is maintained as an engineering notebook rather than a collection of completed code.

Every design is expected to include:

- Problem Statement
- Architecture
- RTL Design
- Testbench
- Simulation Results
- Documentation

The emphasis is on understanding **why** a design works before implementing it.

---

## Long-Term Vision

The long-term objective is to design, verify, synthesize, and implement a complete RISC-V based System-on-Chip on an FPGA while documenting the complete learning and development process.

## Progress

The repository is continuously updated as new concepts are learned, new hardware modules are designed, and more complex digital systems are built.
